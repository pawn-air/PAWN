What the GCS sends without a key or button being pressed
  • While the motors spin (state field time advancing): rc 0 0 0 0 every 0.5 s when no stick is moved (a Tello lands by itself after 15 s without any command).
  • While the motors are off: no rc; command after 5 s without traffic (keeps SDK mode, not logged).
  • Sticks fall back to 0 when no key input arrives for the dead-man time (closed tab, lost Wi-Fi to the laptop).
  • command, streamon, sdk?, sn?, wifi? once, when Connect is pressed.
Nothing else: no automatic landing, no takeoff checks, no geofence. The drone's own firmware may still land or refuse commands — its replies appear in the log exactly as received.
